# docs/perf: 測った数値の記録

> - **状態**: 説明（参考）
> - **対応する実装**: `scripts/perf/`（API の応答時間を測るスクリプト）

このディレクトリのファイルは、「いつ（日付）・どの commit で・どんな条件で」測ったかの記録である。

## 書き方の決まり

- 各ファイルの冒頭に、測った日付、commit、条件（環境・負荷・上流の扱い）を書く
- **記録は後から書き換えない。** 実装を直したり、測り直したりしたときは、既存のファイルを直さず、新しい日付のファイルを足す。誤記を直すときだけ、直した日付と理由をそのファイルに残す
- 数値は、測った時点のものである。現在の値として読まない。現在の値が要るときは、測り直して新しい記録にする
- ファイル名は `YYYY-MM-DD-<題>.md` にする

記録の一覧は [docs/README.md](../README.md) の索引にある。
