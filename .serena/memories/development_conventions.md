# Development Conventions

- **Code Quality:** Enforced using ESLint, Prettier, and TypeScript's strict mode.
- **Commit Messages:** Must follow the [Conventional Commits](https://www.conventionalcommits.org/) specification.
- **Git Hooks:** Husky and lint-staged are used to automatically lint and format code on pre-commit.
- **Branching Strategy:** `main` / `develop` / `feature/*` / `hotfix/*` is mentioned in the `README.md`.
