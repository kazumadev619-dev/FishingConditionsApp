# Task Completion Checklist

Before committing your changes, please ensure you have completed the following steps:

1.  **Linting:** Run `npm run lint` to check for any linting errors.
2.  **Formatting:** Run `npm run format` to ensure your code is formatted correctly.
3.  **Type Checking:** Run `npm run type-check` to check for any TypeScript errors.
4.  **Testing:** Run any relevant unit or E2E tests. (Note: test scripts are not yet fully configured).
5.  **Commit Message:** Write a clear and concise commit message that follows the Conventional Commits specification.
