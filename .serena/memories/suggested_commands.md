# Suggested Commands

All commands should be run from the root directory of the monorepo.

- `npm install`: Install all dependencies for the monorepo.
- `npm run dev --workspace=@fishing-conditions-app/frontend`: Run the frontend development server.
- `npm run build --workspace=@fishing-conditions-app/frontend`: Build the frontend application for production.
- `npm run lint`: Run ESLint to check for code quality issues across the entire project.
- `npm run format`: Run Prettier to format all code in the project.
- `npm run format:check`: Check for formatting issues without modifying files.
- `npm run type-check`: Run the TypeScript compiler to check for type errors.
