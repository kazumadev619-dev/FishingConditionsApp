# Tech Stack

- **Monorepo:** npm workspaces
- **Frontend:**
    - Framework: Next.js, React
    - Language: TypeScript
    - Styling: Tailwind CSS, shadcn/ui
    - State Management: Zustand, React Query
- **Backend (MVP):** Next.js API Routes
- **Backend (Future):** Go
- **Database:** PostgreSQL (Docker/Cloud SQL via Prisma ORM)
- **Caching:** Redis (Upstash)
- **Authentication:** Auth.js
- **Deployment:** GCP (GKE) / kind (local k8s)
- **Testing:** Jest (Unit), Playwright (E2E) - Note: Test scripts are not yet fully configured in the root `package.json`.
