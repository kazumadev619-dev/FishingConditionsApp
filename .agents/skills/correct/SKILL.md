# correct

> **参考元:** [pstack `correct`](https://github.com/cursor/plugins/tree/main/pstack/skills/correct)

同じクラスのミスを何度も注意する状態を終わらせるためのスキル。**注意書きを `AGENTS.md` に足すのは最後の手段**であり、上位の仕組みで「間違えたくても間違えられない状態」を先に狙う。

## 対策の優先順位（上から順に検討する）

1. **アーキテクチャ / API 構造**
   - 誤った呼び出し方や状態の不整合が、モジュール境界・関数シグネチャ・デフォルト設計によってそもそも発生しない形に直す
2. **型 / 静的検査 / Hook / CI ガード**
   - TypeScript の型制約（ブランド型、判別共用体、`satisfies` など）
   - 共通フック（`.agents/hooks/`。Claude Code / Antigravity の双方に効く。[ADR-013](../../../docs/adr/013-multi-agent-customizations.md)）
   - CI ワークフロー（`.github/workflows/ci.yml`）の静的ガード
   - リンター（ESLint / Biome / Oxlint）のカスタムルール・設定
     - **重要制約（`AGENTS.md`）**: `biome.json` / `.oxlintrc.json` / `eslint.config.*` の直接編集は禁止されている。リンター設定の変更が最適と判断した場合は、**ファイルを編集せず設定案と理由だけを提示し、ユーザーの明示承認を得てから変更する**
3. **テスト**
   - 回帰テストや構造テスト（契約・ファイル規約を検証するテスト）で落とす
   - テストや CI ガードを書いたら、必ず [`mutation-test`](../mutation-test/SKILL.md) で「対象のミスを再注入したら落ちる」ことを確かめる
4. **文書 / スキル**
   - 上の 1〜3 では物理強制できない判断基準だけを `.agents/skills/` や `docs/guides/` に短く残す

## 手順

### 1. ミスのクラスを定義する

「今回の1行のバグ」ではなく「何が許されていたから同じ種類のミスが起きたか」を1文で言い切る。

- 良い例: 「`k8s/config.env` の `AUTH_URL` が消えてもビルドとスモークが素通りする」
- 悪い例: 「PR #134 で `AUTH_URL` を書き忘れた」

### 2. 優先順位表の上から強制手段を選ぶ

1（構造）→ 2（型 / hook / CI / lint）→ 3（テスト）→ 4（文書）の順に当てはめ、**最小の変更で最も確実に落ちる層**を選ぶ。選んだ層より上位を見送った理由も 1 行で書けるようにする。

### 3. 実装と実証（壊して落ちることを確かめる）

- 選んだ手段を最小スコープで実装する（無関係なリファクタを混ぜない）
- **必須**: 対象のミスを意図的に再現したとき、追加した仕組みが**分かりやすいエラーメッセージ付きで確実に止める**ことを実行して確かめる
  - テスト / CI ガード: [`mutation-test`](../mutation-test/SKILL.md) の `mutate.py` を使う
  - フック（`.agents/hooks/`）: ユニットテストまたは模擬入力でブロックと通過（誤検知なし）の両方を確かめる
  - 型制約: 不正な呼び出しで `npm run type-check` が落ちることを確かめる（確認後に一時変更は消す）

### 4. 既存の注意書きを削れるか見る

機械的に防げるようになったら、`AGENTS.md` や `.agents/skills/` に重複して残っている長い注意書きを短くするか削る（`principle-subtract-before-you-add`）。

## 出力の形

```markdown
## 潰したミスのクラス
- 症状: <繰り返していたミス>
- 選んだ層: <1. 構造 / 2. 型・hook・CI・lint / 3. テスト / 4. 文書>
- 上位を見送った理由: <あれば 1 行>

## 変更内容
- <変更したファイルとガードの仕組み>
- （リンター設定変更が必要な場合は「未適用・要承認」として案のみ記載）

## 実証結果
- 再現（落ちること）: <実行したコマンドとエラー出力の要点>
- 正常系（誤検知しないこと）: <実行したコマンドと結果>
```
